# Gastei

Controle de gastos pessoal: anote gastos e receitas e veja quanto gastou no dia, na semana, no mês e no ano.

Funciona como app no celular (abra o link e escolha "Adicionar à tela inicial"), sem internet e sem cadastro. Os dados ficam salvos só no aparelho.

## Baixar

- Android: [Gastei.apk](https://github.com/ramosluskka-arch/gastei/releases/download/app/Gastei.apk)
- PC (instalador): [Gastei-Setup.exe](https://github.com/ramosluskka-arch/gastei/releases/download/pc/Gastei-Setup.exe)
- PC (portátil): [Gastei-PC.exe](https://github.com/ramosluskka-arch/gastei/releases/download/pc/Gastei-PC.exe)
